# Launch Checklist

Before shipping anything, I run through this.  
Not every item applies every time (but every item is worth a thought)

## Product

- [ ] Success metric defined (and measurable).
- [ ] Kill criteria defined: what would make us stop?
- [ ] Edge cases handled.
- [ ] Rollback plan ready.

## Users

- [ ] Onboarding or first-run experience exists.
- [ ] Help / FAQ updated.
- [ ] Support team briefed.

## Data

- [ ] Analytics events set up.
- [ ] Dashboard ready.
- [ ] Baseline captured before launch.

## Team

- [ ] Engineering sign-off.
- [ ] Design sign-off.
- [ ] Stakeholders informed.

## After launch

- [ ] 24-hour check — anything broken?
- [ ] 1-week review — metrics moving?
- [ ] 1-month retro — keep, iterate, or kill?
