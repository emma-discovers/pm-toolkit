## Question 1

What does the `range(5)` function return?

- A) [0, 1, 2, 3, 4]
- B) [1, 2, 3, 4, 5]
- C) [0, 1, 2, 3, 4, 5]
- D) [1, 2, 3, 4]

**Correct answer:** A

**Explanation:** `range(5)` generates numbers from 0 up to (but not including) 5.

## Question 2

Which loop is best when the number of iterations is unknown?

- A) `for` loop
- B) `while` loop
- C) `do-while` loop
- D) Nested loop

**Correct answer:** B

**Explanation:** A `while` loop continues until a condition becomes false, making it suitable when the number of iterations is not known in advance.
